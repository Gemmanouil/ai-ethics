“Use the best code.” Simulated LLM Output

function solve() { console.log('Hello world'); }

Completely ignores your actual intent.

No problem solved.

    Improved Prompt:

“Use the fastest code for the problem I present: [insert problem].” Simulated LLM Output

“For the problem ‘find the largest number in a list’, here is an efficient Python solution: python

def largest(nums): return max(nums)

This is optimal because it uses Python’s built‑in C‑optimized function.” Analysis

Responds in the correct language.

Solves the actual problem.

Explains why the solution is efficient.

Much safer and more predictable.

    Original Prompt:

“What’s the best engine?” Simulated LLM Output

“The best engine is the Rolls‑Royce Trent 1000. It is powerful and efficient.” Analysis

The model guesses you meant jet engines.

Could have guessed car engines, game engines, or search engines.

Shows how ambiguity leads to irrelevant or misleading answers.

    Improved Prompt:

“Could you find me the best engine for a specific car speedwise?” Simulated LLM Output

“For top‑speed performance in production cars, the Bugatti W16 quad‑turbo engine is among the strongest options. It produces over 1500 horsepower and enables speeds above 400 km/h.” Analysis

Now the model understands the domain (cars).

Understands the metric (speed).

Gives a relevant, factual answer.

Still could be improved by specifying which car, but it’s far better.
